# Basketball UWB/LPS Tracking Pipeline
[English](README.md) | Русский

Это edge-сервис для трекинга игроков: он принимает поток событий сенсоров (или их симуляцию), приводит время к общей шкале, оценивает состояние движения (позиция/скорость), считает базовую аналитику и пишет поток в удобный формат для replay/debug.

Пакет специально разделён на слои, чтобы можно было заменить симуляцию на реальные UWB/IMU адаптеры и постепенно дорастить MVP до рабочей системы.

## Структура проекта

### `main.py`
Точка входа прикладной логики и CLI-режимов (`lps` / `tdoa`). Здесь выбирается источник событий, запускается `TrackingEngine`.

### `models.py`
Доменные типы и контракты обмена данными (`Envelope`, измерения, fused state, командные метрики).

### `clocks.py`
Модуль выравнивания времени между источниками и edge-host временем. В демо он простой, но архитектурно это место для offset/skew/drift-компенсации сенсоров.

### `sensor_fusion.py`
Оркестрация сенсорного фьюжна вокруг Kalman-модели: IMU идёт в predict, позиционные измерения в update. Математическое ядро Kalman вынесено в `filters/kf_core.py`, а здесь остаётся логика работы с типами сенсоров и quality.

### `analytics.py`
Потоковая аналитика поверх уже оценённого трека (скорость, дистанция, агрегаты по игроку и команде).

### `storage.py`
Выходной слой (sink) для записи состояний и метрик, сейчас NDJSON для replay и отладки. Его можно заменить на Kafka/DB/WebSocket.

### `simulation.py`
Симулятор источников данных для запуска без железа. Умеет как базовый путь (LPS+IMU), так и демонстрационный TDoA-путь, где позиции сначала проходят через `tracking_mvp/filters/`.

### `pipeline.py`
Сборка runtime-конвейера: per-player trackers, clock alignment, sensor fusion, analytics и периодические team metrics. Это основной orchestration-слой, который прогоняет поток событий через систему.

### `filters/`
Подпакет с модулями RTLS-пайплайна: адаптер sync-состояния, TDoA builder, multilateration, quality gates, Kalman/IMM и общий Kalman core. Внутри есть отдельный `filters/README.md` с последовательностью шагов.
